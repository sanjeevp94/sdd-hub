# Feature: 000-example-feature
## Overview
Welcome to the Spec-Driven Development Hub!

This is an example specification designed to show you where to place your specifications and how they should look.
This document represents Phase 1 (Specify) of the SDD lifecycle.

## What is this feature?
This feature serves as a demonstration of the Spec Kit workflow. It acts as a static placeholder to verify that the SDD Dashboard is properly loading specifications from the `specs/` root folder.

## User Stories
- As a new developer, I want to see an example feature so that I understand where specifications belong.
- As an SDD Dashboard user, I want to see this file rendered in the dashboard UI.
