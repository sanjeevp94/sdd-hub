# Spec-Driven Development Hub

This is an interactive dashboard for GitHub Spec Kit designed for a multi-repo workspace structure. It allows you to:
- View specifications generated by Spec Kit (`specs/`)
- Interactively add mock comments and feedback to specifications
- Learn the Spec Kit lifecycle via an onboarding tutorial

## Installation & Setup

We use `uv` for lightning-fast dependency management.

1. Ensure `uv` is installed (`pip install uv`).
2. Run the application using `uv`:

```bash
uv run run.py
```

## Structure
- `dashboard/` contains the Python FastAPI logic.
- `specs/` contains the actual GitHub Spec Kit instance with its configuration, templates, and specifications.
